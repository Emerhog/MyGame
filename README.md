# ⛏ MiniCraft — шаблон 2D-игры в стиле Minecraft

Простой шаблон песочницы на **PHP + JS + HTML + CSS** без внешних зависимостей.

## Как это работает

| Файл        | Роль |
|-------------|------|
| `index.php` | Генерирует мир (холмы, деревья, озеро) в виде двумерного массива блоков и отдаёт его клиенту как JSON + HTML-разметку страницы |
| `game.js`   | Игровой движок: рендер на Canvas, физика (гравитация, коллизии), управление, разрушение/установка блоков, хотбар, частицы, FPS |
| `style.css` | «Пиксельный» интерфейс в духе Minecraft: HUD, хотбар, подсказки |

## Запуск

```bash
php -S localhost:8000
# затем откройте http://localhost:8000
```

## Управление

- **A/D** или **←/→** — ходьба
- **W / ↑ / Пробел** — прыжок
- **ЛКМ** — сломать блок (в радиусе ~5 блоков)
- **ПКМ** — поставить выбранный блок
- **1–6** или **колесо мыши** — выбор блока в хотбаре

## Типы блоков

air, grass, dirt, stone, wood, leaves, sand, water, plank, brick —
добавляйте новые в `BLOCKS` (PHP) и `BLOCK_DEFS` (JS).

## Что можно расширить

- Сохранение изменённого мира на сервер (`save.php` + fetch)
- Тайлы-текстуры вместо заливок
- Мобы, день/ночь, крафт
